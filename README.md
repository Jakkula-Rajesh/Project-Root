# GVCC Solutions – Product Showcase & Enquiry  
Full-Stack Assignment (React + Node.js + SQL)

## 📝 Overview
This application demonstrates a complete full-stack workflow:

- React frontend (product browsing, search/filter, details, enquiry form)
- Node.js + Express backend (REST API)
- SQLite database (products + enquiries)
- Responsive UI + client-side validation
- Admin endpoint to fetch enquiries

---

## 🚀 Tech Stack
### Frontend
- React (CRA)
- React Router
- Axios  
- CSS (custom)

### Backend
- Node.js + Express
- SQLite3
- dotenv
- body-parser
- CORS

### Database
- SQLite (zero-install)
- SQL schema + seed data provided
